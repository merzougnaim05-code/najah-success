# جمعية النجاح الثقافية 🎓

موقع عصري متكامل لجمعية النجاح الثقافية: **واجهة حديثة (SPA) + خادم + قاعدة بيانات**.

## المزايا

**الواجهة العامة**
- صفحة رئيسية عصرية (شعار، مميزات، ثقة، دعوة للتسجيل)
- تسجيل الطلبات: الاسم ← الهاتف ← الطور ← المادة ← الأستاذ ← التوقيت
- صفحة الأساتذة (بحث وتصفية حسب الطور/المادة)
- **تتبع حالة الطلب** برقم الهاتف (خذ رقم المرجع بعد التسجيل)
- صفحة تواصل معنا + إرسال رسائل
- صفّتا القانون الأساسي والقانون الداخلي

**لوحة الإدارة (بعد تسجيل الدخول)**
- إحصائيات حية: إجمالي / مقبول / بانتظار الرد / مرفوض
- جدول طلبات مع بحث وتصفية وترقيم صفحات وقبول/رفض/تعديل/عرض/حذف
- إدارة الأساتذة (إضافة/حذف لكل طور ومادة)
- رسائل الزوار
- إعدادات الموقع (الاسم، الشعار، الهاتف، البريد، التوقيتات...) + تغيير كلمة المرور

## التقنيات

| طبقة | التقنية |
| --- | --- |
| الواجهة | React 18 + Vite + React Router (SPA) |
| الخادم | Node.js + Express |
| قاعدة البيانات | SQLite (مدمجة عبر `node:sqlite` — لا حاجة لأي خادم DB) |
| المصادقة | كوكي موقّع (JWT + HMAC) مع تجزئة كلمة المرور بـ scrypt |

## التشغيل

### المتطلبات
- Node.js **22.13 أو أحدث** (يُستعمل `node:sqlite` المدمج)

### وضع التطوير (يسهّل التعديل)
```
npm install
npm run dev
```
- الواجهة: http://localhost:5173
- الخادم (API): http://localhost:3001 — الواجهة تمرّر طلباتها عبر وكيل تلقائيًا

### وضع الإنتاج (يبني الواجهة ويخدمها الخادم نفسه)
```
npm install
npm run build      # يبني الواجهة في client/dist
npm start          # خادم واحد على http://localhost:3001
```

## البيانات الافتراضية

| الغرض | القيمة |
| --- | --- |
| حساب الإدارة | `admin` / `admin123` |
| طلبات تجريبية | 3 طلبات بحالات مختلفة |
| أساتذة | 22 أستاذًا موزعين على الأطوار والمواد |

> ⚠️ غيّر كلمة المرور من **لوحة التحكم ← الإعدادات** بعد أول دخول.

### إعادة تعيين البيانات
```
npm run reset-data
```
حذف قاعدة البيانات تلقائيًا من `server/data/`، ثم أعد تشغيل الخادم ليعيد التهيئة.

### إشعارات البريد (اختياري)
عند التسجيل، يُرسل إشعار إلى البريد المضبوط في إعدادات الجمعية
(يُستعمل [FormSubmit](https://formsubmit.co) — بدون خادم بريد). فعّله من استمارة التسجيل أو ضبط `notify_email` في لوحة الإدارة.

## متغيرات البيئة (اختيارية)

| المتغير | الافتراضي | الوصف |
| --- | --- | --- |
| `PORT` | `3001` | منفذ الخادم |
| `NAJAH_SECRET` | قيمة ثابتة | سر توقيع الجلسات — غيّره في الإنتاج |
| `NAJAH_ADMIN_PASSWORD` | `admin123` | كلمة مرور حساب الأدمن عند أول تهيئة |
| `NAJAH_COOKIE_SECURE` | غير مفعّل | اجعله `1` عند النشر عبر HTTPS |

## ملاحظة npm (Windows)

إذا ظهر تحذير `install-scripts` ورفض البناء، اسمح بسكربت esbuild:
```
npm install-scripts approve esbuild
```

## البنية

```
server/            خادم Express + قاعدة SQLite
  index.js         REST API + تقديم الواجهة المبنية
  db.js            المخطط + تهيئة البيانات
  auth.js          تجزئة كلمة المرور والتوقيع
client/            واجهة React (SPA)
  src/pages/       الصفحات العامة وصفحات الإدارة
  src/components/  نافذة، شريط، تذييل، شارة، تنبيهات
  src/context/     حالة التطبيق (المستخدم، بيانات الموقع، التنبيهات)
  src/api.js       عميل واجهات الخادم
```
